# Folder structure: source vs build artifacts

Two kinds of paths sit in this repo: **source Cursor wrote and git tracks**, and **artifacts npm/CDK generate and gitignore**.

Workspaces: `infra`, `packages/shared`, `services/api`, `web`.

Related: [one-time-setup.md](one-time-setup.md) (laptop/AWS CLI), [runbook.md](runbook.md) (operator values from `cdk-outputs.json`).

---

## Created by npm / CDK (not in git)

These appear after `npm install`, `npm run build`, `npm run synth`, or `npm run deploy`. They are gitignored (see `.gitignore`: `node_modules/`, `dist/`, `cdk.out/`, `cdk-outputs.json`).

```
smartshop/
├── node_modules/              # npm install
│   ├── @smartshop/api    → ../services/api
│   ├── @smartshop/shared → ../packages/shared
│   ├── @smartshop/web    → ../web
│   └── infra             → ../infra
├── web/dist/                  # npm run build -w @smartshop/web  (Vite)
│   ├── index.html
│   └── assets/
│       ├── *.css
│       └── *.js
├── infra/cdk.out/             # npm run synth / npm run deploy
│   ├── SmartShopStack.template.json
│   ├── SmartShopStack.assets.json
│   ├── manifest.json
│   ├── .cache/
│   └── asset.<hash>/          # bundled Lambda + copied SPA
└── cdk-outputs.json           # npm run deploy  (ApiUrl, CloudFrontUrl, …)
```

Hashed filenames under `web/dist/assets/` and hashed `infra/cdk.out/asset.*` folders change on each build. Do not hard-code those names.

## Which command creates what

| Command | What it creates |
| --- | --- |
| `npm install` | `node_modules/`, updates `package-lock.json` |
| `npm run build` | typecheck only for `@smartshop/shared`; **no extra folder** (`tsc --noEmit`) |
| `npm run build -w @smartshop/web` | `web/dist/` |
| `npm run synth` | `infra/cdk.out/` |
| `npm run deploy` | refreshes `infra/cdk.out/`, writes `cdk-outputs.json`, uploads to AWS |

`cdk deploy` also runs the Vite build, copies `web/dist` into a hashed `infra/cdk.out/asset.*` folder, then publishes that to S3/CloudFront.

Safe to delete anytime: `node_modules/`, `web/dist/`, `infra/cdk.out/`. Recreate with `npm install` and `npm run deploy`. Do not commit them.
