## Safer alternatives (avoid risky `--force` or major breakage)

### React Router v6 — avoid jumping to v7 immediately

1. **Short-term mitigations (code, no major bump):**
   - Treat **`location.state.from.pathname`** (e.g. in `LoginPage`) as untrusted: allow only same-origin paths matching `^/[a-zA-Z0-9/._-]*$` (or a strict allowlist), default to `"/"`.
   - Avoid passing **user-controlled** strings into `<Link to={...}>` or `navigate(userInput)`.
   - SSR hydration CVE: **no action required** unless you add SSR later.

2. **Patch-line alternative (if you must reduce CVE noise without v7):**
   - Check whether React Router publishes **6.x patches ≥7.18.0** (audit currently only offers **7.18.4**). If none, **overrides on 6.30.6 do not help**.

3. **When ready for v7:**
   - Follow [React Router v6 → v7 upgrade guide](https://reactrouter.com/upgrading/v6).
   - Run `web` unit tests and smoke auth, checkout, and deep links.

### esbuild — avoid breaking CDK

1. **Preferred:** Bump **only** `infra` `esbuild` to **^0.28.2** and run **`cdk synth`**. CDK 2.x generally tolerates newer esbuild for asset bundling; this repo does not reference esbuild directly in `infra/lib` — it is a **declared devDependency**, likely for CDK/node resolution.

2. **Optional monorepo-wide pin (if nested 0.24.2 reappears):** Root `overrides` `"esbuild": "0.28.2"` — test **infra synth** and **`web` dev/build** (Vite already uses modern esbuild).

3. **Accept residual risk temporarily:** If synth fails on 0.28.x, document that GHSA-67mh-4wv8-2f99 applies to **esbuild serve**, not CDK bundle paths, and **do not run** `esbuild --serve` on 0.24.2 with untrusted browser tabs on the same machine.

### undici / `@cursor/sdk` — avoid breaking Connect

1. **Do not override `undici` to ≥6.28.0** without testing `@cursor/sdk`: `@connectrpc/connect-node@1.7.0` pins **`undici ^5.28.4`**; forcing 6.x may break the agent at runtime.

2. **Safer operational alternatives:**
   - Run `audit:agent` / `pr-audit-agent.ts` only in **locked-down CI** (egress allowlist, no production credentials on that job).
   - **Replace or gate** the script: skip SDK when `CURSOR_TO_GIT_API_KEY` is unset (already partially done); or use a non-SDK path for audit **suggestions** (static template, Dependabot, or `npm audit` JSON only).

3. **Dependency alternative:** If Cursor publishes a SDK version on **undici 6.x** / newer connect-node, upgrade **`@cursor/sdk`** as a normal semver bump (no `--force`).
